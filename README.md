# 🎮 Steam Swapper

Steam Swapper is a lightweight Windows desktop application that helps you organize and switch between multiple Steam accounts quickly.

It provides a simple dark-mode graphical interface where every account can be assigned a number, a Steam login, and a custom note. The application then lets you select an account and restart Steam using that login.

Steam Swapper does **not** store Steam passwords, does **not** bypass Steam Guard, and does **not** modify Steam accounts.

> If you use third-party accounts, make sure you have permission to access them and understand Steam's applicable rules and risks.

---

## ✨ Features

- Dark-mode Windows interface
- Account list with shortcut numbers from `0` to `100`
- Steam login field
- Custom notes for each account
- Add, edit, remove, and refresh account entries
- One-click Steam account switching
- Automatic Steam installation detection
- External local account database
- Custom app logo and Windows icon
- PyInstaller-ready standalone `.exe`
- No password storage
- Steam Guard remains fully controlled by Steam

## 💾 Account Database

Steam Swapper automatically creates:

```text
steam_contas.txt
```

next to the Python script or compiled executable.

The file stores account information using this format:

```text
NUMBER|LOGIN|NOTE
```

Example:

```text
1|main_account|Main account
10|eldenring_account|Elden Ring
20|forza_account|Forza Horizon 5
```

The database stores only:

- account number;
- Steam login;
- note.

It does **not** store passwords.

# 🚀 Running from Source

## 1. Install Python

Install a recent version of Python for Windows.

Make sure Python is available in your terminal:

```cmd
python --version
```

---

## 2. Install Development Dependencies

From the project folder, run:

```cmd
pip install -r requirements.txt
```

The current `requirements.txt` installs:

```text
PyInstaller
Pillow
```

These packages are needed for building the standalone Windows executable.

The Steam Swapper application itself uses Python's standard library for its runtime features.

---

## 3. Run Steam Swapper

Run:

```cmd
python steam_swapper.py
```

The graphical interface should open immediately.

# 🧭 Using Steam Swapper

## Adding an Account

Click:

```text
+ Add Account
```

You will be asked for three values.

### Account Number

Choose a number between:

```text
0 - 100
```

Example:

```text
10
```

Each number can belong to only one account.

### Steam Login

Enter the Steam login name used to sign in to the account.

Example:

```text
my_steam_login
```

This may be different from the public profile name shown on Steam.

### Note

Add a description that helps you remember what the account is used for.

Examples:

```text
Main account
```

```text
Elden Ring
```

```text
Shared games
```

```text
Forza Horizon 5
```

The account will then appear in the table.

Example:

```text
10 | my_steam_login | Elden Ring
```

---

## Editing an Account

Select an account and click:

```text
Edit
```

You can change:

- the shortcut number;
- the Steam login;
- the note.

Steam Swapper prevents duplicate account numbers and duplicate logins.

---

## Removing an Account

Select an account and click:

```text
Remove
```

Steam Swapper will ask for confirmation.

Removing an entry only deletes it from the local Steam Swapper database.

It does **not** delete or modify the real Steam account.

---

## Refreshing the List

Click:

```text
Refresh
```

to reload the account data from:

```text
steam_contas.txt
```

This is useful if the file was changed externally.

---

## Switching Steam Accounts

Select an account and click:

```text
SWITCH ACCOUNT
```

Steam Swapper will:

1. detect the Steam installation;
2. close the currently running Steam client;
3. wait for Steam to shut down;
4. force-close remaining Steam processes if necessary;
5. restart Steam with the selected login.

Steam remains responsible for authentication.

If Steam asks for:

- a password;
- Steam Guard;
- email confirmation;
- mobile confirmation;

complete those steps directly in Steam.

---

# 🔎 Steam Detection

Steam Swapper first checks the Windows Registry.

It looks for Steam information under common Valve registry locations.

If Steam is not found there, it also checks common locations such as:

```text
C:\Program Files (x86)\Steam\steam.exe
```

```text
C:\Program Files\Steam\steam.exe
```

```text
C:\Steam\steam.exe
```

No user-specific Windows path is hardcoded into the application.

---

# 🌙 Dark Mode

The application uses a custom dark interface.

It also attempts to enable the native Windows dark title bar through the Windows DWM API.

The main interface uses a dark background with blue selection highlights and an orange primary action button.

---

# 🔐 Security

Steam Swapper does not store Steam passwords.

The local account file contains only information similar to:

```text
15|my_account|Elden Ring
```

Steam Swapper does not:

- read Steam passwords;
- save Steam passwords;
- decrypt Steam credentials;
- bypass Steam Guard;
- disable Steam authentication;
- modify Steam account security.

All authentication remains handled by the official Steam client.

# 🏗️ Building the Windows EXE

## First Build — Generate `.spec` and `.exe`

If you do not have `SteamSwapper.spec` yet, run:

```cmd
pyinstaller --clean --noconfirm --onefile --windowed --name "SteamSwapper" --icon "img\2.ico" --add-data "img\2.png;img" --add-data "img\2.ico;img" steam_swapper.py
```

This generates:

```text
SteamSwapper.spec
build/
dist/
```

The compiled executable will be:

```text
dist\SteamSwapper.exe
```

---

## Rebuilding After Code Changes

Once `SteamSwapper.spec` exists, you normally only need:

```cmd
pyinstaller --clean --noconfirm SteamSwapper.spec
```

The updated executable will again be created at:

```text
dist\SteamSwapper.exe
```

You do **not** need to reinstall PyInstaller or Pillow every time you edit the code.

# 🛠️ Troubleshooting

## The old version still opens

If you changed `steam_swapper.py` but launch:

```text
dist\SteamSwapper.exe
```

you are running the last compiled version.

Rebuild it:

```cmd
pyinstaller --clean --noconfirm SteamSwapper.spec
```

---

## The icon is missing

Verify that these files exist:

```text
img\2.png
img\2.ico
```

The `.ico` file must be a real Windows ICO file, not a PNG renamed to `.ico`.

A good ICO file should contain multiple sizes, such as:

```text
16x16
24x24
32x32
48x48
64x64
128x128
256x256
```

---

## PyInstaller reports that Pillow is missing

Install project dependencies:

```cmd
pip install -r requirements.txt
```

or:

```cmd
pip install pillow
```

Then rebuild the application.

---

## Steam cannot be found

Make sure Steam is installed normally on Windows.

Steam Swapper checks the Windows Registry and the most common Steam installation folders.
